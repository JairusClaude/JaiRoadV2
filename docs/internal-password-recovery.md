# Retired internal password recovery

Public Forgot Password, internal one-time recovery requests and passkey authentication have been removed from the active JaiROADS application. Do not run the old internal recovery SQL setup. Users who cannot sign in must contact their authorized SuperAdmin, who can use the existing account-management password reset with password reauthentication. The separately approved owner procedure remains applicable to SuperAdmin recovery. Password changes and two-factor authentication remain available. Any previously created tables or credentials are retained as historical data until a database owner reviews retention; no destructive database migration is performed.

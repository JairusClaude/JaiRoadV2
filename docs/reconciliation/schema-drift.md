Current bridge aggregates: **3 Fortify users, 3 canonical links, 0 legacy links, 0 dual links, 0 missing canonical targets, 0 duplicate links, 0 email/hash mismatches, 0 canonical accounts lacking a bridge**. Only aggregate comparison booleans/counts were returned; credential values were not exported. One active unlinked Admin exists, so grandfathering is an actual compatibility requirement. No active account or active assignment currently references a Retired profile.

Six FK columns lack a leading-column supporting index: RoadCoverage.created_by, MaintenanceProject.created_by, MaintenanceRecord.created_by, MaintenanceDocument.uploaded_by, Media.uploaded_by and AuditLog.user_id. This is a workload/performance review item, not a missing FK or a correctness failure. Use realistic EXPLAIN/traffic before adding indexes. Recipient feed index is `(recipient_user_id,created_at DESC)`; adding ID as a final descending tie-break key may help its existing ordering, subject to measurement. A future period UNIQUE already begins with project_id; assess redundant-index costs without dropping the current project index in this task.
